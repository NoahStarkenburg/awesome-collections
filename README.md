# awesome-collections

A monorepo of small AI / developer-tooling projects, each self-contained and
shippable on its own. Pulls together three production-ready tools plus a
curated reference list — all under a single repo so they share CI, lint
rules, and contribution conventions.

## Projects

### `dep-upgrade-skill/` &nbsp;·&nbsp; [README](./dep-upgrade-skill/README.md)

A Claude Code skill that tells you **which lines in your repo break** when
you bump a dependency. Cross-references release-note breaking changes
against real call sites — so you get a markdown report grouped by breaking
change, with `file:line` refs, instead of a generic changelog summary.

Worked examples against React 18 → 19 and Express 4 → 5 in
[`dep-upgrade-skill/examples/`](./dep-upgrade-skill/examples/).

> "/upgrade-impact react 18 19"

### `screenshot-search-mcp/` &nbsp;·&nbsp; [README](./screenshot-search-mcp/README.md)

A FastMCP server that indexes a folder of screenshots and exposes search by
**OCR text** (via Tesseract) and **visual content** (via CLIP embeddings).
Works with any MCP client — Claude Desktop, Cursor, Cline, Continue, Zed.

Eight tools cover indexing, status, text search, visual search, image-to-
image similarity, single-shot OCR, and metadata + EXIF.

> "Find the screenshot from 3 weeks ago with the auth error message."

### `personal-timeline-mcp/` &nbsp;·&nbsp; [README](./personal-timeline-mcp/README.md) · [PRIVACY](./personal-timeline-mcp/PRIVACY.md)

A FastMCP server that aggregates your local activity — browser history,
git commits, filesystem mtimes, and `.ics` calendar events — into a single
queryable timeline. **Strictly local**: no network calls, no OAuth, no
cloud sync. See `PRIVACY.md` for exactly what's read.

Eight tools support listing sources, indexing, time-window queries,
free-text search, daily summaries, and cross-source correlation.

> "What changed in the auth code today and what meeting prompted it?"

### `awesome-mcp-clients/` &nbsp;·&nbsp; [README](./awesome-mcp-clients/README.md)

A curated list of clients that speak the
[Model Context Protocol](https://modelcontextprotocol.io). Server lists
are everywhere; verified client lists are sparse, so this fills the gap.

Entries are generated by a small `pipeline/fetch.py` helper — metadata
comes from the GitHub API directly so nothing is hand-edited.

## Quick start

```bash
git clone https://github.com/NoahStarkenburg/awesome-collections.git
cd awesome-collections

# Pick the project you want and follow its README. Each is self-contained
# with its own install instructions:
cd screenshot-search-mcp        # → ./screenshot-search-mcp/README.md
```

The MCP servers declare their dependencies in their `pyproject.toml`. The
Python helpers in `dep-upgrade-skill` are stdlib-only.

## Engineering

| Concern | Where |
| --- | --- |
| **CI** — pytest + ruff on every push/PR | [`.github/workflows/ci.yml`](./.github/workflows/ci.yml) |
| **Release** — per-project tag-driven CD | [`.github/workflows/release.yml`](./.github/workflows/release.yml) |
| **Dependency updates** — weekly via Dependabot | [`.github/dependabot.yml`](./.github/dependabot.yml) |
| **Contributor guide** | [`CONTRIBUTING.md`](./CONTRIBUTING.md) |
| **Security policy** | [`SECURITY.md`](./SECURITY.md) |
| **Shared lint config** | [`pyproject.toml`](./pyproject.toml) |

CI runs the full test matrix across Linux + Windows for Python 3.11 and
3.12. Lint and format are enforced with [ruff](https://docs.astral.sh/ruff/).

## Releases

Each project releases independently via a per-project semver tag:

```bash
git tag screenshot-search-mcp-v0.1.0
git push origin screenshot-search-mcp-v0.1.0
```

The release workflow verifies the pyproject version matches the tag,
builds wheel + sdist, smoke-tests the artifact, and publishes a GitHub
Release with auto-generated notes. See `CONTRIBUTING.md` for the full
release procedure.
