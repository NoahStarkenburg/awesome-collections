# Sample screenshots

This folder is intentionally empty in the repo. Drop your own screenshots
here to follow `examples/sample_run.md` against real data.

Suggested seed set for testing:

- 2–3 images of error dialogs (good for `search_text` and `search_visual`)
- 2–3 images of regular UI (login screens, settings pages)
- 1 photo (jpg from a phone, to exercise EXIF in `get_metadata`)

Any file matching the supported extensions in `index.py` will be picked up:
`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`, `.webp`, `.tiff`, `.tif`.
